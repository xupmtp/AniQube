# 片庫卡片以作品為單位，只在同一片源頻道內合併

第一版一個播放清單就是一張卡片，結果同一部動畫散成好幾張同名卡：國語與日語配音各一個清單，各季也各一個清單（Ani-One 的《我的英雄學院》每季只有兩集試看，其餘為會員限定，散成六張卡）。我們決定卡片改以作品為單位，只在同一片源頻道內合併。同一頻道內，下列任一條件成立就算同一部作品：

1. 標題去掉季數與配音標記後相同；
2. 共用的 YouTube 影片超過較小那部的一半（「全部集數」與單季清單互相重疊；只共用幾支的混合清單不算）；
3. 對到同一個 AniList 編號（同一部作品的粵語版與日語版清單常取不同譯名，例如「Dr.STONE」與「Dr.STONE 新石紀」）；
4. 在 AniList 上互為續集或前傳（「續」「完」「The Final Season」這類名稱差很多的續作）。只用續集／前傳這種主線關係，不用外傳、衍生。

合併後，名稱不同但對到同一個 AniList 編號、語言互補的季，視為同一季的配音版。作品名取有原聲首季的那份裡最短的名稱。季的順序：標題有季數就照季數，沒寫季數的依 AniList 首播時間插入。劇場版等單篇也歸入所屬作品。合錯的用 repo 內的人工作品對應表（`manual-works.json`）指定，被指定的作品不參與自動合併。

## Considered Options

只看標題：最初的做法，實際跑下來同一部作品的不同清單常取不同譯名，合不起來。用 AniList 續集／前傳關聯：一開始以為要多一次查詢而放棄，其實能加進原本取作品資料的那次查詢裡，不多花請求。跨片源頻道合併（Muse 與 Ani-One 都有同一部）：要處理兩邊集數重疊與配音版重複，留待之後。維持一季一卡、只在作品頁連到其他季：改動最小，但首頁與搜尋結果仍是一堆同名卡。

## Consequences

作品頁網址、繼續觀看與我的片單都改以作品為單位，上線初期的舊網址與瀏覽器紀錄直接作廢。各季的題材、評分、封面要彙整成作品的一份（卡片顯示最新一季，篩選用所有季的聯集）。AniList 把有些獨立的系列標為續集（《BanG Dream! It's MyGO!!!!!》與《Ave Mujica》、《怪醫黑傑克》TV 版與《21》），這類要寫進人工作品對應表拆開；對應到錯的 AniList 條目也會連帶合錯。
