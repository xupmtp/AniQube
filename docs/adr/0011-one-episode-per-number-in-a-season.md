# 一季裡同一個集數只有一集：撞號的依標題拆開

ADR 0010 讓作品頁每個集數只列一次之後，35 部作品有 312 組集數重複的集被藏起來：頻道的季清單裡混了外傳或別的系列（「地下城」第一季清單裡有《劍姬神聖譚》、「工作細胞 第二季」裡有 BLACK）、兩種配音（SPY 第二季清單同時有【日語】【國語】）、兩季（騰訊「全職高手」清單有第一、二季）、合集影片（「EP01-12一口氣」）、重複上傳（吞噬星空 41 集上傳兩次、天竺鼠車車「日本重播版」、星辰變「優化版」）、上下兩半的集（Re:0「第1A話／第1B話」）。我們決定照規則處理，不為個別作品設例外：

1. **清單依標題拆開**：每一集取「系列框」（標題扣掉集數、【】、頻道與版本字樣，有《》的取《》與附近的中文；保留季數與「小故事」「迷你動畫」「特別篇」這類字樣），配音也算進去。跟主體（配音同清單、系列框最像清單名的那組）**集數撞號**的組拆出去，當成另一份清單交給既有規則決定歸屬：同一份清單拆出來的組照系列鏈判斷要不要併回同一部作品（ADR 0007），形式像劇場版、OVA、特別篇的歸到劇場版與特別篇。不撞號的併回主體（頻道偶爾寫法不同）。合輯不在這一步拆，合輯裡沿用前一集季數時只限同一個系列框（「鑽石王牌S2」後面接「act2」不算第 2 季），屬於別部作品某一季的集不收，判斷不出季、系列框是作品名後面多了字的用它當季名（「工作細胞系列」裡的「BLACK」）。
2. **合集移出季**：寫了範圍的（「EP01-06」），範圍裡有單獨上傳的集才移出；沒寫範圍的（「Full Version」「精編版」）片長是這份清單一般集的 1.5 倍以上才移出。移出的交給合集規則（ADR 0006），能補缺集才收。
3. **重複上傳只留一支**：同集數、標題扣掉版本字樣相同、片長差不到 1 分鐘的；或標了重播版、優化版、純淨版而同一集已有沒標的。整季都是另一個版本、集數都在另一季裡的也不另列。
4. **上下兩半各算一集**：「第1A話」「EP240上」是上半、B／下是下半，兩支都列，顯示「240上」「第 240 集（下）」。
5. **集數**：先看【】外面（「第222話【圍裙神探第二話】」是 222）；【】裡只有集數的（「【第55回】」）才用裡面的。一半以上撞號的清單（高木同學「小故事」每話好幾段）集數不能用，照上架時間重新編號。

## Considered Options

在作品頁把同集數的幾支都列出來：觀看者分不出哪支是本傳，配音、片源的聯集也沒辦法對齊。只依配音或只依季數標記拆：外傳、迷你動畫、小故事沒有這些標記。不管撞不撞號一律依系列框拆：頻道標題寫法常常前後不一，會把一季切成很多份。

## Consequences

2026-11 重建後重複的集從 312 組降到 1 組（誅仙3 兩支不同內容都標 EP62，頻道標錯，只會顯示一支）。拆出來的清單沒有自己的 AniList 對應時列進 report 的「未對應」；同一份清單拆出的組 ID 是「清單ID@第一支影片ID」。驗證：逐支比對重建前後每部作品的影片，少掉的只能是重複上傳、版本重播、移出的合集。
