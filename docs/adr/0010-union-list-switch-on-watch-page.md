# 作品頁的集數列表是配音版與片源的聯集，切換只在播放頁

作品頁原本要先選片源、再選配音，集數列表只列那個組合的集：全職高手第 1 季騰訊 23 集、閱文 17 集互補，要切片源才看得全；選了國語，原聲有、國語沒有的集顯示「無此配音」。我們決定**作品頁不再有配音與片源選單**：每一季的集數列表是所有配音版、所有片源的聯集，同一集只列一次，播哪一支依序看：原聲 → 其他配音；同一配音再看能站內播 → sync 排的預設片源。**播放頁**在集名右邊的動作列（分享、下一集旁）用兩個小下拉選配音（只列這一集有的）與片源（只列這一集在目前配音下有的），只有一個就不顯示；不放在列表上方，免得看起來像在篩選列表。一集最多 2 配音 × 2 片源 4 支。切換只換正在看的那一支，不記住，列表、下一集仍照上面的預設挑；看過以第幾集為準。劇場版與特別篇比照，作品頁不再有配音選單。

## Considered Options

作品頁保留配音選單、只拿掉片源：列表仍會有「無此配音」的空列，觀眾也得在兩個地方切換。片源標在每一列：作品頁的目的就是不必管片源，標了只是雜訊。

## Consequences

`work.ts` 的列表、上下一集都在聯集裡照預設挑（`unionRows`、`nextSpot`、`prevSpot`），切換用 `dubChoices`、`sourceChoices`。

2026-11 修訂：原本切換過會記成這部作品的偏好（`aniqube:prefs:works`），列表與下一集都跟著換；改成只換那一支，作品頁列表永遠是預設版本，偏好拿掉。
