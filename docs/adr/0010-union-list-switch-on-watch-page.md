# 作品頁的集數列表是配音版與片源的聯集，切換只在播放頁

作品頁原本要先選片源、再選配音，集數列表只列那個組合的集：全職高手第 1 季騰訊 23 集、閱文 17 集互補，要切片源才看得全；選了國語，原聲有、國語沒有的集顯示「無此配音」。我們決定**作品頁不再有配音與片源選單**：每一季的集數列表是所有配音版、所有片源的聯集，同一集只列一次，播哪一支依序看：這部作品記住的偏好配音 → 原聲 → 其他配音；同一配音再看偏好片源 → 能站內播 → sync 排的預設片源。**播放頁**側邊選配音（只列這一集有的），播放器下方一行選片源（只列這一集在目前配音下有的，只有一個就不顯示），一集最多 2 配音 × 2 片源 4 支。在播放頁切換過就記成這部作品的偏好（存在本機），列表、下一集都照它挑；看過以第幾集為準。劇場版與特別篇比照，作品頁不再有配音選單。

## Considered Options

作品頁保留配音選單、只拿掉片源：列表仍會有「無此配音」的空列，觀眾也得在兩個地方切換。片源標在每一列：作品頁的目的就是不必管片源，標了只是雜訊。

## Consequences

`work.ts` 的列表、上下一集都改成照偏好在聯集裡挑（`unionRows`、`nextSpot`、`prevSpot`），切換用 `dubChoices`、`sourceChoices`。偏好存在 `aniqube:prefs:works`，作品 ID 轉址時一起搬，清除觀看紀錄時一起清；沒有放進備份檔。
