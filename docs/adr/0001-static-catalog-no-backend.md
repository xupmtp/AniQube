# 片庫每日建置成靜態檔，不設後端

YouTube Data API 的搜尋額度一天只有 100 次，網站的搜尋與排序不可能即時轉打 YouTube，片庫必須自己存一份。我們決定不設後端與資料庫：排程工作每天同步一次片源頻道，產出片庫 JSON 並提交回 repo，前端是純靜態單頁應用，搜尋、篩選、排序全在瀏覽器內完成。這樣 API 金鑰不會出現在瀏覽器、營運成本為零，也沒有伺服器要維護。

## Consequences

片庫最多落後片源頻道一天，新上架或下架的集要等下次同步才反映。任何需要伺服器狀態的功能（帳號、跨裝置同步、留言）都做不了，繼續觀看與我的片單只能存在觀看者的瀏覽器。片庫成長到前端載入變慢時，要先拆檔案，再考慮加後端。
