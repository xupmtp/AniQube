# 作品跨片源頻道合併，名稱用模糊比對

ADR 0003 只在同一片源頻道內合併，同一部動畫在兩個頻道就是兩張卡。加入曼迪與閱文後重疊變多（閱文與騰訊有《斗破蒼穹》《狐妖小紅娘》等），用 `excludeSeasons` 一筆筆排除不再可行，而且會丟掉資料：《擅長捉弄人的高木同學》Muse 只有第 3 季、Ani-One 只有第 1 季，排除掉一邊就少一季。我們決定所有頻道一起分組：

1. 合併條件沿用 ADR 0003 的四條，不分頻道，另加一條**模糊比對**：作品名正規化（簡繁、大小寫、標點）後，相鄰兩字的 Dice 相似度 ≥ 0.8 就合併；但 AniList 標明兩者是外傳、衍生、平行作品（SPIN_OFF、SIDE_STORY、ALTERNATIVE、PARENT）時不併。只靠模糊比對合起來的配對列進 `report.json` 的 `fuzzy`，每週覆核（`docs/match-review.md`）。
2. 同一季在好幾個頻道都有時，每個頻道是那一季的一個**片源**，觀看者可以切換；預設是站內能播集數最多的，其次集數，再其次 `sources.json` 的頻道順序。
3. 作品 ID 用 `sources.json` 裡最前面的那個頻道算，加新頻道時舊作品的 ID 不變。分組改變造成 ID 變動時，`index.json` 的 `moved` 記下舊 ID → 新 ID，前端轉址並搬移本機紀錄。

## Considered Options

名稱互相包含就合併：命中率高，但「Love Live!」包含在「Love Live! Sunshine!!」裡，實測 18 萬組已知不同的作品中有 10 組錯併。Dice 門檻：以片庫實測，≥ 0.7 有 7 組錯併、≥ 0.8 剩 2 組（其中一組其實是漏併的同一部），錯的都是同系列外傳，交給 AniList 關聯否決。同一季重複時自動只留一份：介面最單純，但不同頻道的翻譯、能否站內播放不一樣，觀看者想選。

## Consequences

`groupWorks` 一次處理所有頻道，配音版以「片源＋語言」區分；作品頁與播放頁多一個片源選單（只有一個片源時不顯示），配音選單只列目前片源的（後來改成作品頁顯示聯集、只在播放頁切換，見 docs/adr/0010）。卡片仍歸一個頻道（`channel`），只用來算 ID。不同頻道的影片 ID 不同，合輯是否被單季涵蓋只能在同一頻道內判斷。
