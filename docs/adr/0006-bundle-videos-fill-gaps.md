# 合集影片只收能補上缺集的，作品頁另列一區

片源頻道常上傳「一支影片連看好幾集」的合集：Muse 的【全集馬拉松】、Ani-One 的「第1~12話 合集」、騰訊與閱文的「EP1-EP20合集」「S1-S3一口氣」，長度從半小時到十幾小時。原本的「正片」定義是一支影片一集或一部劇場版，超過 3 小時的一律濾掉（多半是直播存檔、連播），標題含「合集」「馬拉松」的也被當成精華剪輯擋掉，結果約 1,300 支合集都不在片庫裡。其中不少是唯一能看的版本：很多國漫的單集只有第 1 集免費、其餘會員限定，合集卻是公開的；有些作品頻道根本沒開單集清單。

我們決定合集另外處理，不算一般的集：

1. **辨認**：不在任何季、也不是單篇的影片，標題像合集（合集、全集、一口氣、馬拉松、EP1-20、第1~12話、S1-S3），長度 30 分鐘到 24 小時；預告、精華、高光、小劇場、名場面等另有排除清單（`sources.json` 的 `bundleDeny`）。
2. **範圍**：從標題解析集數範圍與季（「EP101-115」「第 3 季 第 1–17 集」；跨好幾季的「S1-S3」不指定季；什麼都沒寫的是整部「全集」）。
3. **歸屬**：作品名取《》裡的；《》是篇名時取前面、是宣傳字時取後面；依序比對片庫的作品，對不到才自成一部（只有合集的作品照樣收）。
4. **只留能補缺集的**：範圍裡有作品沒有的集數（會員限定、沒單獨上傳），或整季不在片庫／含會員限定集；範圍重疊的，每次挑補得最多的一支。合集用全系列總集數、片庫的季每季從 1 起算時（SPY 第 2 季「第30-35話」），那季沒有會員集且合集整段在它的最後一集之後，視為編號不同、不算缺集。
5. **呈現**：作品頁在集數之後另列「合集」區（第 1–45 集、12 時 51 分），播放頁標題是「合集 第 1–45 集」；不算進卡片的「N 集可看」，也不參與作品合併（合集對到的 AniList 只拿來補題材與封面）。

## Considered Options

全部保留：最完整，但一部國漫常有十幾支互相重疊的合集（「EP200-218」「EP211-216」…），作品頁會很亂。維持過濾、只對個別作品人工白名單：每週都要人工處理新上傳的合集。把合集拆進集數列表（缺的集數顯示「在合集 EP1-20 觀看」）：最貼近使用習慣，但要能精準對上每一集的編號，各頻道編號方式不一，先不做。

## Consequences

片庫從 645 部增加到 696 部（51 部原本沒有任何單集可看），86 部作品有合集區。一般集數的 3 小時上限不變。範圍解析不到的合集歸為「全集」，只在作品沒有單集或有會員限定集時才收。
