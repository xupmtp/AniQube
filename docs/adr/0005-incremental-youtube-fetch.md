# YouTube 資料改為增量抓取，每週完整同步一次

每天完整抓五個頻道要約 3,300 單位（每日上限 10,000），而且每加一個頻道就照比例增加。多申請一組憑證輪流用違反 YouTube API 的開發者政策（不得為同一應用程式開多個專案規避配額），所以改成只抓變動的部分。頻道每天會上架新集、也會因授權到期下架，兩邊都要抓得到：

- **上傳清單、會員清單**：新的在前面，翻到上次見過的影片就停。
- **播放清單**：摘要每次全抓（便宜）；影片數或 etag 跟上次不同才重抓內容。清單移除集數會讓影片數變少，當天就發現。
- **影片細節**：新影片一定查；舊影片依 ID 分成七組，每天輪流重查一組。刪除、設為私人、改成禁止嵌入、台灣不能看，最慢七天內發現。上次查不到的影片（清單裡的私人佔位）記在快取的 `gone`，同樣輪到那天才重查。
- **每週日（台灣時間）完整同步一次**，跟過去每天做的一樣，補上增量沒看到的變化（例如會員限定改成公開）。`FULL_SYNC=1` 可手動觸發；快取裡沒有的頻道（新加的）自動完整抓。

## Considered Options

兩組憑證輪替：直接違反政策，可能兩個專案一起被停用。申請提高配額：仍可做，但審查要時間，且用量本來就能大幅降低。用 ETag 條件請求：304 回應仍計配額，省不了多少。每天重查全部影片細節：最即時，但影片細節是用量的大宗。

## Consequences

平日約 150～400 單位（模擬：第二天起 148 單位），週日約 3,300。已下架但影片數沒變的集，最慢七天才會從片庫消失；這段期間點下去會看到播放器的「前往 YouTube 觀看」退路。觀看次數等統計最慢七天更新一次。快取（`data-cache` 分支）成了增量的基準，壞掉或遺失時那個頻道自動退回完整同步。
