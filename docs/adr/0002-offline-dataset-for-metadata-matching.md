# 用離線資料集把季對應到 AniList

片源頻道的清單標題是台灣譯名，而題材、評分、首播時間的來源 AniList 沒有中文標題欄位。我們決定在建置時用 anime-offline-database 這份離線資料集做對應：它的別名收了大量繁體譯名，且每筆條目直接帶 AniList 編號。對不上的季由 repo 內的人工對應表補，人工填的不會被自動結果覆蓋。

## Considered Options

先用 Bangumi 搜出日文原名、再查 AniList：台灣與中國譯名常不同，要連打兩個搜尋 API，命中率不可控。直接用 AniList 搜尋中文標題：它沒有中文欄位，幾乎搜不到。初步實測 36 個台灣譯名，離線資料集在只做標點正規化時命中 29 個。

## Consequences

資料集採 ODbL 授權，網站必須標示出處，衍生的對應表也要以同授權公開。同一譯名對到多季時靠標題季數與首集上架年份判斷，會有錯，錯的要靠人工對應表修。
