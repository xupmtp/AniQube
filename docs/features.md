# 功能清單

研究依據：[research/feature-gap-vs-streaming.md](research/feature-gap-vs-streaming.md)（與 Netflix、動畫瘋、Crunchyroll 的功能落差）。

## 已完成
- 有新集標記、首頁「片單有更新」列
- 卡片預覽（桌面滑鼠停留放大、觸控點擊彈出底部面板）：播放、加入片單、從繼續觀看移除
- 觀看紀錄管理：看過打勾（播放超過 30 秒）、清除觀看紀錄（觀看紀錄頁單部、設定頁全部）
- 繼續觀看卡片的進度條
- 「我的片單」頁（加入時間／最近更新排序）、「觀看紀錄」頁（以作品為單位，依最後觀看時間排序，可繼續或清除紀錄）
- 設定頁（個人選單 → 設定）：自動播放下一集（播放頁也有同一個開關）；暫停記錄觀看紀錄（觀看紀錄頁會提示）；清除全部觀看紀錄；備份與還原（匯出／合併匯入，設定一起帶走，音量除外）
- 瀏覽頁篩選：題材與標籤合成一列「題材」，依作品數排序，平常列前 12 個與已選的，其餘收在「更多」；面板點外面或按 Esc 收起；排序剩人氣、評分、趨勢、最近更新、觀看數（觀看數是片庫收錄影片的 YouTube 觀看次數加總）
- 題材、標籤可點：作品頁、首頁主打推薦、預覽卡上的題材與標籤點了跳到瀏覽頁並只套用該條件（作品卡片本身是連結，卡片上的文字不另外做連結）
- 音量與靜音自動記住，換集、重新整理後沿用（跟著裝置，不進備份檔）
- 自動下一集：播完在播放器下方倒數 5 秒、可取消；關閉時停在原地並提示「下一集」
- 播放頁快捷鍵：空白鍵／K、← →、0～9 跳到 0%～90%、F、M、N／P
- 分享：作品頁、播放頁（可選從目前秒數開始，網址帶 ?t=）、手機底部面板；系統分享選單或複製連結
- 資料品質自動化：push 時用 `data-cache` 分支的快取重建（0 配額）；每週一 05:00 雲端排程照 `docs/match-review.md` 覆核對應並直接提交
- 作品頁集數列表改成配音版與片源的聯集，配音、片源只在播放頁切換、只換那一支影片（docs/adr/0010）
- 一季裡同一個集數只有一集：清單裡撞號的外傳、別配音、別季依標題拆開，合集移出季，重複上傳只留一支，上下兩半各列一集（docs/adr/0011）
- 幾乎只有會員限定的作品不收（docs/adr/0009）：有會員集、可看不到 12 集且不到 1/3；被拿掉的列在 report.json 的 memberLocked
- 作品內整理（docs/adr/0008）：合輯拆進各季、季名統一為「第 N 季 副標」、集名取出副標（狐妖小紅娘等騰訊／閱文作品不再同名）、劇場版與 OVA 移到「劇場版與特別篇」並標示類型、集數列表可切換舊到新／新到舊
- 分群規則化（docs/adr/0007）：系列鏈（不經過劇場版的續作關係）判斷劇場版、合輯能不能串連兩個系列；重製版、系列形式外傳不合併；混合清單、跨作品合輯自動不收；人工作品對應表與排除清單清空，五個頻道同一組參數（最短 2 分鐘，騰訊多出約 1,300 集正片）
- 跨頻道合併（docs/adr/0004）：同一部動畫不分頻道是同一部作品；名稱 Dice 相似度 ≥ 0.8 也合併（AniList 標明外傳的不併）；同一季多個頻道上傳時可切換片源；作品 ID 改變時舊網址轉址、本機紀錄搬移
- 會員限定標示：含會員限定集的作品，卡片右下角顯示鎖頭（大多數是會員集時為金色），預覽卡寫「84 集中 83 集會員限定」
- 彈出視窗（分享、快捷鍵）點外面、按 Esc 或點進播放器就關閉；橫列捲動時收起預覽卡
- 合集（docs/adr/0006）：一支影片連看好幾集的合集，只收能補上缺集的（會員限定、沒單獨上傳），作品頁另列「合集」區；51 部原本沒有單集的作品因此能看
- 中文簡介補強：播放清單沒寫說明時改用第 1 集影片說明（要提到作品名才用），Muse 取【劇情簡介】段落；英文簡介從 266 部降到 12 部
- 簡介再清一輪（2026-11-23）：只有合集、劇場版單支影片的作品，標題《》是這部作品也採用影片說明；認得【劇情大綱】【故事大綱】；分隔線、「▮支持」「➨訂閱」、「更多精彩動漫」片單之後整段不要；hashtag、代碼、「線上看」「播放清單」「播放地區」「免費收看」等宣傳行刪掉；作品名去掉【木棉花電影院】。英文簡介 17 → 10 部，剩下的頻道沒寫中文簡介（只有宣傳或各集目錄）
- 頻道：Muse木棉花、Ani-One、騰訊視頻、曼迪、閱文動畫
- 增量抓取（docs/adr/0005）：平日只抓變動（約 150～400 單位），上架、清單下架當天反映，影片本身下架最慢七天；每週日完整同步一次（`FULL_SYNC=1` 可手動）
- 合輯拆季：合輯開頭單季都沒有的集自動拆成第一季（無職、入間、香格里拉等），能跟其他季一樣用下拉選
- 中文簡介：改用頻道播放清單說明（規則式清掉宣傳行、表情符號，騰訊轉繁體），清不出來退回 AniList 英文並標「英文簡介」；作品頁預設 4 行可展開

## 待辦（資料品質）
- **剩餘的未對應清單**：2026-11-20 再清一輪（`manual-matches.json` 358 筆），`unmatched` 剩 10、`guessed` 剩 1。剩下的在 AniList 找不到：《人中之龍 Powered by 日本統一》《叫我，對大哥(Web版)》《澈底對你成癮》《閃爍的青春》《惡魔戰線》《混在末日，独自成仙》《死灵法师！我即是天灾》《万古神帝》《顾长歌：我！天命大反派》《暴走哈姆醬》；《灵剑尊》會員搶先看清單分不出是第幾季，維持猜的。之後每週一的雲端排程照 `docs/match-review.md` 處理新的 `unmatched`／`guessed`。

## 暫緩（不一定要做）
- **相似作品列**：作品頁在集數之後放「相似作品」橫列，首頁加「因為你看了《X》」。資料用 AniList 的 recommendations（只留片庫有的），不足 12 部用題材、標籤重疊最多的補；看過的作品從推薦排除。2026-11 決定先跳過。

## 不做
- 新番時間表、RSS／iCal 訂閱、跳過片頭按鈕：2026-11-18 確定不做
- 彈幕、留言：需要後端，彈幕還會遮擋播放器（違反 YouTube 條款）
- 下載離線：YouTube 條款禁止
- 自動跨裝置同步、推播：需要後端（ADR 0001）
- 自訂播放器控制列：YouTube 標題列關不掉、畫質 API 已停用，換了反而功能變少
