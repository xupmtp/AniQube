# 功能清單

研究依據：[research/feature-gap-vs-streaming.md](research/feature-gap-vs-streaming.md)（與 Netflix、動畫瘋、Crunchyroll 的功能落差）。

## 已完成
- 有新集標記、首頁「片單有更新」列
- 卡片預覽（桌面滑鼠停留放大、觸控點擊彈出底部面板）：播放、加入片單、從繼續觀看移除
- 觀看紀錄管理：看過打勾（播放超過 30 秒）、清除觀看紀錄
- 繼續觀看卡片的進度條
- 備份與還原：右上角個人選單匯出／匯入備份檔（合併匯入）
- 「我的片單」頁（加入時間／最近更新排序）、「觀看紀錄」頁（以作品為單位，依最後觀看時間排序，可繼續或清除紀錄）

## 進行中（依序，每項上線驗收後再做下一項）
1. 自動下一集開關、鍵盤快捷鍵
2. 分享按鈕
3. 相似作品列
4. 中文簡介（改用頻道播放清單說明；要先跑一次完整同步並抽查各頻道品質）

## 暫緩（不一定要做）
- **新番時間表**：依星期列出連載中作品在 YouTube 上片的時段。資料可從 `sync/cache/raw.json` 每集的上架時間算出（`npm run rebuild`，不花配額）。動畫瘋、Crunchyroll 都有。2026-11 決定先跳過。
- **RSS／iCal 更新訂閱檔**：沒有推播時最接近「更新提醒」的做法，但會用訂閱檔的觀眾少。
- **跳過片頭按鈕**：價值高，但片頭時間要人工標記，且 YouTube 條款對自訂跳轉按鈕沒有明文，屬灰色地帶。

## 不做
- 彈幕、留言：需要後端，彈幕還會遮擋播放器（違反 YouTube 條款）
- 下載離線：YouTube 條款禁止
- 自動跨裝置同步、推播：需要後端（ADR 0001）
- 自訂播放器控制列：YouTube 標題列關不掉、畫質 API 已停用，換了反而功能變少
