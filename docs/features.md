# 功能清單

研究依據：[research/feature-gap-vs-streaming.md](research/feature-gap-vs-streaming.md)（與 Netflix、動畫瘋、Crunchyroll 的功能落差）。

## 已完成
- 有新集標記、首頁「片單有更新」列
- 卡片預覽（桌面滑鼠停留放大、觸控點擊彈出底部面板）：播放、加入片單、從繼續觀看移除
- 觀看紀錄管理：看過打勾（播放超過 30 秒）、清除觀看紀錄
- 繼續觀看卡片的進度條
- 備份與還原：右上角個人選單匯出／匯入備份檔（合併匯入）
- 「我的片單」頁（加入時間／最近更新排序）、「觀看紀錄」頁（以作品為單位，依最後觀看時間排序，可繼續或清除紀錄）
- 設定頁（個人選單 → 設定）：自動播放下一集開關；播放頁也有同一個開關
- 自動下一集：播完在播放器下方倒數 5 秒、可取消；關閉時停在原地並提示「下一集」
- 播放頁快捷鍵：空白鍵／K、← →、0～9 跳到 0%～90%、F、M、N／P
- 分享：作品頁、播放頁（可選從目前秒數開始，網址帶 ?t=）、手機底部面板；系統分享選單或複製連結
- 中文簡介：改用頻道播放清單說明（規則式清掉宣傳行、表情符號，騰訊轉繁體），清不出來退回 AniList 英文並標「英文簡介」；作品頁預設 4 行可展開

## 待辦（資料品質）
- **剩餘的未對應清單**：`report.json` 的 `unmatched` 還有 105 個播放清單沒對上 AniList，這些作品缺題材、標籤、評分與封面（多為特別篇、OVA、總集篇，或離線資料集沒有台灣譯名的新作）。另有 87 個 `guessed`（用猜的對應）建議抽查。修法：寫進 `manual-matches.json` 後 `npm run rebuild`。
- **跨頻道合併**：2026-11-18 檢查三個頻道，同一部作品跨頻道重複的只有《擅長捉弄人的高木同學》（Muse 三季 35 集、Ani-One 第一季 12 集），已在 `sources.json` 的 `excludeSeasons` 排除 Ani-One 那兩份、以 Muse 為主。代理授權大多不重疊，暫不做通用的跨頻道合併；之後新增頻道時重新檢查（判斷方式：不同頻道的作品任一季對到同一個 AniList 編號，或作品名相同／互相包含）。

## 暫緩（不一定要做）
- **新番時間表**：依星期列出連載中作品在 YouTube 上片的時段。資料可從 `sync/cache/raw.json` 每集的上架時間算出（`npm run rebuild`，不花配額）。動畫瘋、Crunchyroll 都有。2026-11 決定先跳過。
- **相似作品列**：作品頁在集數之後放「相似作品」橫列，首頁加「因為你看了《X》」。資料用 AniList 的 recommendations（只留片庫有的），不足 12 部用題材、標籤重疊最多的補；看過的作品從推薦排除。2026-11 決定先跳過。
- **RSS／iCal 更新訂閱檔**：沒有推播時最接近「更新提醒」的做法，但會用訂閱檔的觀眾少。
- **跳過片頭按鈕**：價值高，但片頭時間要人工標記，且 YouTube 條款對自訂跳轉按鈕沒有明文，屬灰色地帶。

## 不做
- 彈幕、留言：需要後端，彈幕還會遮擋播放器（違反 YouTube 條款）
- 下載離線：YouTube 條款禁止
- 自動跨裝置同步、推播：需要後端（ADR 0001）
- 自訂播放器控制列：YouTube 標題列關不掉、畫質 API 已停用，換了反而功能變少
